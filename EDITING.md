# Editing the conference website

Open `dist/index.html` in a browser to view the website. No installation or build is needed. It can also be uploaded to GitHub Pages: publish the contents of `dist`.

## Change any wording

Open `dist/index.html` in a plain-text or HTML editor. Every visible heading, paragraph, menu label, name, date, address, hotel detail, and the single design credit is ordinary HTML text. Search for the words and replace them, preserving the surrounding tags. Save and reload the browser. The architectural gate inscription is also an HTML text element, not the inscription embedded in the background artwork.

The speaker list appears twice: once on Home and once on Speakers. Update both lists and the corresponding talk entry under Program. The alphabetical-order note is retained.

The `href` attribute controls link destinations; update email `mailto:` and telephone `tel:` destinations if their visible wording changes. The document title and search description are near the start of the file.

`dist/styles.css` controls appearance. `dist/script.js` controls navigation and the mobile menu. There are no external dependencies, accounts, or editing subscriptions.

## Artwork

The header and building use cropped CSS views of the exact approved homepage image. The original image file remains untouched. Its screenshot text is concealed; all displayed page wording is live HTML. The original Canton Tower, six-pillar gate, narrow river, and red-brick building are preserved. The two unwanted bottom captions remain absent. The gate has an editable light-red inscription.

## Content requiring confirmation

- The source HTML provides the 17 speaker names. Names distorted in the visual mockup were not copied.
- The full organizing committee, registration arrangements, detailed program, talk titles, abstracts, and lecture room were not supplied and remain marked for announcement.
- Transportation follows https://lsongsysu.github.io/CSAGS-VII/directions/index.html . Journey times are estimates from that guide.
- Hotel addresses, telephone numbers, and walking times follow https://lsongsysu.github.io/SYSUAGW26/accommodation/index.html . That page concerns May 22–24, 2026; those stay dates are deliberately not carried over. December reservations require confirmation.

Edits to a downloaded copy are local until the updated files are uploaded to the hosting provider. The deployed Sites version is private until its sharing setting is changed.
